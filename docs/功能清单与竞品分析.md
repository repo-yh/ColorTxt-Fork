# 功能清单与竞品分析

> 2026-06 产品规划时整理（用户提供），作为功能规划参考快照，与当前代码可能有出入。

## ColorTxt 已实现功能

- **本地文件阅读**：单个 .txt/.md 打开 + 整个目录递归导入；.epub 转 .md 加载
- **流式读取**：按块读取，降低大文件加载压力；自动编码识别（UTF-8 / ANSI）
- **章节**：自动识别（内置规则 + 自定义规则）；章节标题常驻顶部
- **个性上色**：自定义高亮规则着色、自定义高亮词（角色/关键词突出）、划线笔记 + 笔记
- **定制配色**：阅读区/高亮词/划线配色；明亮/暗黑主题
- **排版**：字体/字号/行高可调（内置京華老宋体）、空行压缩、行首缩进、简繁互转、全半角互转
- **辅助**：阅读进度恢复、最近打开（20 个）、文件列表（分类/排序/过滤）、内容查找、全文搜索、书签（带备注）
- **体验**：全屏阅读、区域宽度可调、多窗口、摸鱼快捷键（快速隐藏）
- **AI**：阅读助手（剧情分析、思维导图、词云图）、角色卡生成（角色摘要 + 文生图立绘）、AI 智能排版（硬换行/标点修正）、编辑模式
- **语音朗读**：Edge TTS / 系统语音 / 阿里云通义

## 竞品差距分析（微信读书、静读天下、Apple Books 等）

1. **阅读数据与统计**：阅读时长统计、每日阅读报告、阅读目标/连续打卡、预估读完时间
2. **书籍管理**：书籍封面/元信息展示、书架概念（现有偏目录浏览）、自定义书单
3. **笔记导出**：划线笔记导出 PDF/Word、笔记检索与批量导出
4. **阅读体验**：护眼/夜读模式、翻页动画、阅读速度提示、视力保护提醒
5. **AI 增强**：章节摘要自动提取、关键情节时间线、人物关系图谱
6. **格式扩展**：.mobi / .azw3 / .cbr / .cbz
7. **其他**：内置查词词典（Tabfile/MDict 已实现）、阅读成就/里程碑、笔记分享生成图片
