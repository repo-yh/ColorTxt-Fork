# 存储与发布参考

## userData 目录架构

项目**未调用 `app.setPath`**，完全依赖 Electron 默认，目录名由 `package.json` 的 `"name": "colortxt"` 决定：Windows `%APPDATA%\colortxt`、macOS `~/Library/Application Support/colortxt`、Linux `~/.config/colortxt`。

| 用途 | 相对路径 | 源码 |
|------|---------|------|
| localStorage（LevelDB） | `Local Storage/leveldb/` | Chromium 管理 |
| 窗口位置 | `window-bounds.json` | `src/main/windowBounds.ts` |
| API 密钥（加密） | `ai/secrets.v1.json` | `src/main/secretStorage.ts` |
| AI 数据/模型缓存 | `ai/data/`、`ai/model-cache/` | `src/main/ai/infra/paths.ts` |
| 书源数据库 | `book-sources.db` | `src/main/bookSource/store/bookSourceStore.ts` |
| 书源脚本 | `book-source/files/` | `bookSource/engine/scriptImport.ts` |
| 书源 Android ID | `bookSourceAndroidId.txt` | `bookSource/engine/bookSourceUserAgent.ts` |
| 章节离线缓存 | `book_cache/` | `bookSource/engine/chapterCache.ts` |
| 电子书转 txt | `ConvertedTxt/` | `src/preload/index.ts` |
| 角色立绘缓存 | `CharacterPortrait/` | `src/preload/index.ts` |
| 找书下载 | `DownloadedBooks/` | `src/preload/index.ts` |
| 更新器临时目录 | `tmp/` | `src/main/updater.ts` |

**localStorage Key 对照**：`colorTxt.ui.settings`（全部界面/阅读配置，含 globalHighlightWords、高亮色）、`colorTxt.file.meta`（按文件路径聚合的书签/进度/高亮词/标注等）、`colorTxt.file.list`、`colorTxt.recent.files`、`colorTxt.session`、`colortxt:replaceRules:app` / `:findBook`。**AI 密钥不在 localStorage**。

**IPC 路径链路**：主进程 `app.getPath("userData")` → IPC `app:getPath`（异步）/`app:getPathSync`（sendSync，白名单键名）→ preload `getUserDataPath()` / `getPath(name)` → 渲染层 `defaultCacheDirs.ts` 解析缓存目录。

**便携版**：`process.env.PORTABLE_EXECUTABLE_DIR` 检测（electron-builder 便携版启动器注入），当前仅用于禁用应用内自动更新；无 userData 重定向。

## AI 密钥存储

- 路径 `<userData>/ai/secrets.v1.json`，格式 `{ version: 1, backend: "safeStorage" | "appBound", values: Record<SecretSlotId, string(加密 base64)> }`
- `safeStorage` → Electron `safeStorage.decryptString()`（Windows 可用）；`appBound` → AES-256-GCM + 派生密钥（跨平台）
- IPC（`src/main/registerSecretsIpc.ts`）：`secrets:export`/`import`（原始文件读写）、`secrets:get`/`set`（单密钥封装）；preload 暴露 `secrets.exportSecrets()` / `importSecrets()`
- 配置导入导出：密钥以 `colorTxt.secrets.raw` 键随配置 JSON 同步保存；文件不存在时导出返回空字符串

## 便携版更新机制

- **electron-builder 只为 NSIS target 生成 `latest.yml`**，不为 portable 生成；electron-updater 硬编码只读 `latest.yml` → 便携版天然无应用内自动更新
- 手动上传 exe 到 GitHub Release 会缺 `latest.yml`，NSIS 版检查更新也会报错。**必须 `electron-builder --publish always`（带 GITHUB_TOKEN）发布**，不能手动传二进制
- 便携版方案：`checkPortableUpdates()` IPC 读 `process.resourcesPath/app-update.yml` 用 `js-yaml` 解析 `publish.owner/repo` → 请求 GitHub Releases API 最新版 → 语义化比较 → 弹窗引导「打开下载页」（`shell:openExternal` 跳 Releases 页手动下载）。不走 electron-updater（成员全 private、事件驱动不适合直接判断）

**electron-updater 源码**：核心逻辑在 `node_modules/electron-updater/out/AppUpdater.js`（`checkForUpdates` ≈ L253）；`.d.ts` 只有类型。调试直接看 JS 实现。

## 替换文件功能（右键菜单）

```
FileListPanel「替换文件」emit("replaceFilePath")
  → ReaderSidebar 透传 → App.vue onReplaceFilePath(oldPath)
```

1. `showOpenDialog` 选新 txt/md → `stat` 取 size
2. 更新 `txtFiles`（旧路径换新路径+size，去重）；`recentFiles` 旧路径改新路径
3. 迁移 `fileMetaRecords`：书签/高亮词/标注/角色卡/进度等**全部继承**；`convertedMdPath`/`sourceMtimeMsAtConvert` 清除
4. 旧文件正打开则用新路径重开

涉及：`useFileListMenus.ts`（菜单项）、`FileListPanel.vue`、`ReaderSidebar.vue`、`App.vue`（`onReplaceFilePath` + `replaceFileBaseName`）。

## 拖放文件双路径

| 路径 | 链路 | 结果 |
|------|------|------|
| 拖到阅读区 | `useAppWindowBindings.ts onDrop`（document 全局）→ `collectFsPathsFromDataTransfer`（webUtils.getPathForFile）→ 支持类型判断 → `openFilePath` | 直接打开，蒙层「打开文件」 |
| 拖到侧栏 | `ReaderSidebar.vue @drop.capture="onSidebarDrop"`（`.capture` 先于全局 + `stopPropagation`）→ emit `importDroppedPaths` → `importPathsIntoFileList` | 加入文件列表不打开 |

工具：`utils/dragDropFsPaths.ts`（`collectFsPathsFromDataTransfer`）。蒙层区分：阅读区 `readerDropOverlayVisible`，侧栏 `sidebarDragOverlayVisible` + `isOverSidebarImportDropZone()` 清阅读区蒙层。

## Tabfile 词典格式

- 单文件格式：`.txt/.tab/.tsv/.dic`，每行 `headword\tdefinition`（首个 tab 分隔，词义内 tab 保留）；`##name`/`##description` meta 行
- 查词大小写不敏感二分查找；HTML/纯文本由 `looksLikeHtml`（前 800 字符）判定，纯文本走 `<pre>`，HTML 走 Shadow DOM `DictHtmlFrame`
- CSS 配套：所有 css 文件**全局分配**给所有 tabfile 与 mdict（`groupBundlesByStem`，文件名无需与词典同名）；查词时 `resolveTabfileCss` 剥 `<link>` 死链、内联 `<style>`
- 内存格式与 mdict 一致（`ImportedDictionary`，`kind="tabfile"`），持久化/查词/缓存全复用原链路
- 涉及：`dictionaryTypes.ts`、`tabfileReader.ts`、`importBundles.ts`、`dictionaryService.ts`、`DictionaryManageModal.vue`

## Release CI（.github/workflows/release.yml）

- 触发：push 标签 `v*` 或手动 workflow_dispatch；有「Verify tag matches package.json version」校验步骤
- 矩阵：Windows x64（windows-2025-vs2026）、macOS arm64/x64、Linux arm64/x64
- 步骤：checkout（fetch-depth: 0）→ 版本校验 → 缓存 Electron → `npm ci` → `npx electron-vite build` → `node scripts/prune-pack-deps.mjs` → `npx electron-builder` → artifact → publish job（`electron-builder publish --policy always`，需 `GITHUB_TOKEN`）
- **版本发布流程**：package.json + package-lock.json 同步改并一起提交（`npm ci` 要求严格一致）→ 打 tag `v<version>` → **先推 tags 再推 main，分开推**（一起推只触发 main 的 CI，tags 事件不触发）
- `npm install --package-lock-only` 会触发 postinstall（electron-rebuild 等，约 1 分钟）；Electron 运行时文件锁会致 EBUSY，先关 Electron
